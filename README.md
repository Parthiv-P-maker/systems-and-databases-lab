## 🚀 Current Projects

### 1. System Toolkit Shell Script
A menu-driven Bash toolkit for Linux system management.

**Features include:**
- System information viewer
- CPU information
- Memory usage monitor
- Disk usage checker
- Running process viewer
- Kill process utility
- Network diagnostics
- Ping host tool
- Port availability checker
- File search utility
- Directory size analyzer
- Backup directory to `.tar.gz`
- Archive extraction
- Calculator
- User information viewer
- File permission manager
- Service manager
- Log viewer
- System updater
- Top CPU usage monitor
- Top memory usage monitor
- Date/time display
- Hostname changer
- User creation/deletion
- ShaktiDB service monitor

**Run:**
```bash
chmod +x shell-scripts/system_toolkit.sh
./shell-scripts/system_toolkit.sh
```
